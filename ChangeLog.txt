Release 0.11 (in development)
=============================

* fixed rounding of hours and minutes: 1h59'50" was shown as 1h60'

* fixed the split into days and weeks: the last day of a work
  session crossing the 4am day boundary got four hours too much

* log messages which don't change the status (edits, references,
  release and component changes) no longer stop the report, and
  closing an issue with any disposition ends the work on it

* added issue assignment as a valid status change message

* added reporting by day and week

* code re-factoring
